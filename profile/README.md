# GrooveSheet

[GrooveSheet](https://www.groovesheet.net) turns a recording into sheet music for drums, piano, guitar (with tab) and bass, a chord chart, isolated stems and editable MIDI, and keeps a public library of thousands of songs already transcribed. Built by Kelin Studio Pte. Ltd., Singapore.

## For developers and agents

| Repo | What |
| --- | --- |
| [groovesheet-mcp](https://github.com/groovesheet/groovesheet-mcp) | MCP server client config, the `groovesheet` and `groovesheet-api` skills (`npx skills add groovesheet/groovesheet-mcp`), an Agent Plugins `plugin.json`, the ChatGPT plugin package, `AGENTS.md` |
| [groovesheet-sdk](https://github.com/groovesheet/groovesheet-sdk) | `@groovesheet/sdk` on npm: TypeScript client and the `groovesheet` CLI for the REST API |

- Docs: https://www.groovesheet.net/developers/docs
- REST API: https://api.groovesheet.net/openapi.json, sandbox at https://api.groovesheet.net/sandbox (no token, nothing charged)
- MCP: `https://api.groovesheet.net/mcp/public` (no sign-in), `https://api.groovesheet.net/mcp` (OAuth 2.1)
- For language models and agents: https://www.groovesheet.net/llms.txt, https://www.groovesheet.net/agents.md, https://www.groovesheet.net/auth.md
- Support: support@groovesheet.net
